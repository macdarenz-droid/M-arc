Install

Install M/ARC.

A signed APK for Android, the web app once it has an address, and the source for anyone who wants to read it.

Android APK

Version __VERSION__

The release file is named MARC-v__VERSION__.<run>-signed.apk, where <run> is the CI run number.

Download the APK Releases and changelog

  1. Download the APK from the latest release.

  2. Open the file. The first time, Android asks you to allow installs from your browser or file manager. Allow it for this install.

  3. Tap Install. An update installs over the old version and keeps your data. Android allows that only because every M/ARC build carries the same signing key.

Verify the signature

Every build is signed with one permanent key, and CI checks the fingerprint on each build before an APK is released. You can check it yourself.

Signing key SHA-256. Does not change between versions.

__FINGERPRINT_WBR__

Verify command

apksigner verify --print-certs MARC-v__VERSION__.*-signed.apk

apksigner ships with the Android SDK build tools. If the fingerprint it prints matches the one above, the file was signed by the M/ARC key and has not been altered.

Obtainium

Obtainium can install M/ARC from the GitHub releases page and keep it updated. Add this address as a source:

https://github.com/macdarenz-droid/M-arc

Android refuses an update whose signing key differs from the installed app's, so a swapped file cannot install over M/ARC.

In the browser

Open M/ARC in Chrome, Edge or Samsung Internet on Android and choose Add to Home Screen. It installs as an app and works offline.

Open in the browser

The web app has no public address yet. When it does, this page will carry it. Chrome, Edge and Samsung Internet on Android then offer Add to Home Screen, and M/ARC installs as an app and works offline.

What runs before a release

Every push runs typecheck, 1,487 unit tests in 116 files, run in three time zones, a production build and a visual gate across the five themes before an APK is signed. A release is built on demand from a commit with a green gate.
